## 📌 Branch Directory & Module Details

### 1️⃣ [`html-practice`](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/html-practice) — HTML Foundations & Practice
Contains comprehensive HTML assignments and structured practice tasks:
- **`introduction-to-web/`**: Web architecture, client-server models, HTTP/HTTPS, browser rendering engines, and developer environment setup.
- **`Assignment_2_HTML_Basics/`**: 20 Fundamental exercises covering HTML tags, formatting, lists, links, and tables.
- **`Assignment_3_Semantic_HTML/`**: Semantic layouts (`<header>`, `<nav>`, `<main>`, `<footer>`), online resumes, conference timetables, restaurant menus, and grade reports.
- **`Assignment_4_Forms_Embedding/`**: Interactive forms, input validations, file uploads, iframe embedding (YouTube videos, Google Maps), and UTF-8 encoding.
- **`practice/html/`**: Practical mini-projects:
  - Task 01: Resume Webpage
  - Task 02: College Timetable Layout
  - Task 03: Smart Portal
  - Task 04: Comprehensive Student Registration Form

👉 **[Explore the HTML Practice Branch](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/html-practice)**

---

### 2️⃣ [`css-practice`](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/css-practice) — CSS Styling & UI Components
Focuses on modern CSS styling techniques, layout architectures, and component designs:
- **`practice-codebase/task_05_Student_Card/`**:
  - Semantic HTML markup (`index.html`) & custom CSS (`style.css`).
  - Implements the **CSS Box Model**, skill badge indicators, typography hierarchy, and interactive button states.
- **Concepts Covered:** Selectors, specificity, box model (`margin`, `border`, `padding`, `content`), color schemes, and component styling.

👉 **[Explore the CSS Practice Branch](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/css-practice)**

## 💻 Getting Started & Cloning

# Switch to CSS assignments

git checkout main
