## 🚀 Modules & Assignments Breakdown

### 1️⃣ Assignment 6: CSS Flexbox & Grid Layouts (`ASSIGNMENT_6_SUBMISSION_OF_CSS_FLEXBOX_AND_GRID/`)

Advanced layouts leveraging CSS Flexbox and 2D CSS Grid systems for fluid responsiveness:

| Task / Layout | Description | Core CSS Concepts |
| :--- | :--- | :--- |
| **Blog Layout** | Responsive blog page with featured article, post cards, and sidebar widgets. | `display: grid`, `grid-template-columns`, `gap`, media queries |
| **Dashboard** | Admin dashboard layout with sidebar navigation, header, analytics summary cards, and chart containers. | `grid-template-areas`, `flexbox`, responsive layout structure |
| **Homepage** | Modern landing page with a responsive navbar, hero banner, feature section, and CTA buttons. | `display: flex`, `justify-content: space-between`, `align-items: center` |
| **Personal Portfolio** | Developer showcase page featuring an about section, skills matrix, and interactive project cards. | Flexbox navigation, grid project showcase, responsive stacking |
| **Pricing Section** | Tiered subscription pricing cards (Basic, Pro, Premium) highlighting the recommended tier. | `display: flex`, card scaling, border highlights, button styling |
| **Product Gallery** | E-commerce product catalog with image cards, pricing badges, and responsive auto-fitting grid. | `grid-template-columns: repeat(auto-fit, minmax(...))`, hover zoom |

---

### 2️⃣ Assignment 5: CSS Fundamentals & Box Model (`Assignment_5_SUBMISSION_OF_CSS_BASICS/`)

Foundational styling techniques focusing on layout structure, typography, floats, and CSS box model properties:

| Task / Layout | Description | Core CSS Concepts |
| :--- | :--- | :--- |
| **Dashboard Layout** | Basic multi-pane dashboard layout. | `margin`, `padding`, `border`, `display: inline-block` / `block` |
| **Information Webpage** | Educational/editorial webpage with styled headings, paragraphs, lists, and tables. | Typography hierarchy, line-height, color contrast, table borders |
| **Newspaper** | Traditional newspaper print layout with headlines, multi-column text, and image floating. | `float: left`, `clear`, text wrapping, drop-caps |
| **Personal Portfolio Homepage** | Personal introduction page with navigation bar and section blocks. | Background colors, anchor styling, structural division |
| **Photo Gallery** | Image thumbnail grid displaying photos with caption overlays. | Image sizing, `overflow`, border-radius, figure/figcaption styling |
| **Webpage Layout** | Standard semantic wireframe layout (Header, Nav, Main Content, Sidebar, Footer). | Page structure, semantic tags, box model calculations |

---

### 3️⃣ Practice Codebase (`practice-codebase/`)

Dedicated experiments and modular UI components:

- **CSS Units (`practice-codebase/css_Units/`):** Visual comparison and practical application of absolute units (`px`, `pt`) vs relative units (`%`, `em`, `rem`, `vw`, `vh`).
- **Student Profile Card (`practice-codebase/task_05_Student_Card/`):** Reusable card component featuring avatar styling, badge pills for technical skills (HTML, CSS, Java), and interactive hover buttons.

## 💻 How to Run & Preview

1. Clone the repository and checkout the `css-practice` branch:
   ```bash
   git clone https://github.com/OmGupta723/BridgeLabz-Training-3Y.git
   cd BridgeLabz-Training-3Y
   git checkout css-practice
   ```

2. Open any task in your default browser:
   ```bash
   # Assignment 6 - Modern Flexbox/Grid Blog Layout
   start "ASSIGNMENT_6_SUBMISSION_OF_CSS_FLEXBOX_AND_GRID/Blog Layout/index.html"

   # Assignment 6 - Analytics Dashboard
   start "ASSIGNMENT_6_SUBMISSION_OF_CSS_FLEXBOX_AND_GRID/Dashboard/index.html"
   ```
