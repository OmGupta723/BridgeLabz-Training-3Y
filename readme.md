# 🎨 CSS Practice, Basics, Flexbox, Grid, Animations & Bootstrap

Welcome to the **`css-practice`** branch of the **BridgeLabz Training (3Y)** program! This branch contains an extensive collection of modern CSS assignments, layout architectures (Flexbox & CSS Grid), 2D/3D transformations, keyframe animations, pseudo-classes, responsive design with media queries, and responsive web pages built with the **Bootstrap 5** framework.

## 🚀 Detailed Module Breakdown

### 1️⃣ Assignment 10: Bootstrap 5 Framework & Components (`ASSIGNMENT_10_SUBMISSION_OF_BOOTSTRAP/`)

Implements responsive web interfaces using the **Bootstrap 5** framework, leveraging the 12-column grid system, utility classes, and pre-built components:

| Project | Description | Bootstrap Features & Components |
| :--- | :--- | :--- |
| **01 Company Landing Page** | Corporate homepage with navigation, value proposition, and contact CTA. | `navbar`, `container`, `row`, `col-lg-*`, `btn-primary`, `card` |
| **02 Personal Portfolio Basics** | Developer portfolio showcasing skills, about me, and project highlights. | `badge`, `card`, `grid system`, `rounded-circle`, `text-center` |
| **03 Product Catalog** | E-commerce storefront with responsive product cards, price tags, and ratings. | `card-group`, `card-img-top`, `btn-outline-*`, `g-4` gutters |
| **04 Restaurant Menu Page** | Structured restaurant menu organized into appetizers, mains, and desserts. | `nav-pills`, `list-group`, `d-flex justify-content-between`, `modal` |
| **05 Custom Themed Blog Homepage** | Editorial publication layout featuring hero articles, categories, and author bios. | `display-4`, `text-muted`, `border-bottom`, `breadcrumb` |
| **06 Notifications Dashboard** | Notification center displaying alerts, activity updates, and status messages. | `alert`, `alert-dismissible`, `fade show`, `badge`, `list-group` |
| **07 Task Tracker with Badges** | Task list interface organizing assignments by priority and completion status. | `badge bg-*`, `form-check`, `list-group-item-action`, `progress` |
| **08 Pricing Plans** | Subscription tier comparison cards (Free, Pro, Enterprise) with feature lists. | `card-header`, `card-body`, `shadow-sm`, `w-100 btn` |
| **09 Blog Pagination and Pager** | Navigation widget demonstrating multi-page navigation and next/previous controls. | `pagination`, `page-item`, `page-link`, `active`, `disabled` |
| **10 Travel Agency Showcase** | Travel agency brochure displaying destination cards, itineraries, and banner. | `carousel`, `card-columns`, `btn-success`, `container-fluid` |

### 2️⃣ Assignment 9: Responsive Design & Media Queries (`ASSIGNMENT_9_SUBMISSION_OF_CSS_RESPONSIVE/`)

Focuses on mobile-first responsive web design principles, CSS filters, and viewport adaptations:

| Project | Description | Core CSS Concepts |
| :--- | :--- | :--- |
| **01 Responsive Image Filter Gallery** | Gallery demonstrating CSS filter effects across viewport sizes. | `filter: grayscale() blur() brightness()`, `@media` queries |
| **02 Responsive Web Design Layout** | Multi-device layout adapting between smartphone, tablet, and desktop viewports. | Fluid widths, viewport breakpoints, flexible column stacking |
| **03 Responsive Cards with Media Queries** | Card container transitioning from single-column on mobile to 3-column on desktop. | `@media (min-width: 768px)`, flex-wrap, gap management |
| **04 Responsive Typography** | Fluid font sizing that scales smoothly without jarring breakpoint jumps. | `font-size: clamp(...)`, `calc()`, `rem`, `vw` |
| **05 Filter Cards with Animation** | Interactive cards with combined CSS filters, scale transforms, and transitions. | `transition: all 0.3s ease`, `transform: scale(1.05)`, filter blending |
| **06 Responsive CSS Cheat Sheet** | Practical reference page summarizing CSS media query syntax and device sizes. | Semantic tables, code callouts, syntax reference cards |
| **07 Combined Responsive Web Demo** | End-to-end responsive landing page featuring collapsible navigation and grid content. | Responsive hamburger toggle, media query breakpoints, fluid containers |
| **08 Filter Comparison Layout** | Side-by-side matrices comparing visual effects (sepia, invert, hue-rotate, drop-shadow). | CSS image filters, multi-column comparison layout |
| **09 Responsive Design Principles Summary** | Informative guide explaining viewport meta tag, mobile-first vs. desktop-first. | Layout architecture, fluid grids, responsive imagery |
| **10 Responsive Dashboard Summary** | Responsive administrative interface with collapsing sidebar and responsive KPI cards. | Flexible grid layouts, scrollable table containers, media queries |

### 4️⃣ Assignment 7: CSS Models, Shadows & Transforms (`ASSIGNMENT_7_SUBMISSION_OF_CSS_MODELS/`)

Explores the CSS rendering pipeline, visual models, depth, and spatial transformations:

| Project | Description | Core CSS Concepts |
| :--- | :--- | :--- |
| **borders_padding** | Complex border styling, curved corners, and internal padding dynamics. | `border-radius`, `border-style: dashed/double/solid`, padding spacing |
| **gradinet** | Vibrant color transitions including linear, radial, and conic variations. | `linear-gradient()`, `radial-gradient()`, color stops, angle orientation |
| **height_width** | Box dimensions, min/max constraints, and auto calculations. | `width`, `max-width`, `min-height`, `box-sizing`, percentage dimensions |
| **outline_form** | Form control accessibility showcasing outline offset vs. border styling. | `outline`, `outline-offset`, focus accessibility, form input UX |
| **shadows** | Multi-layered elevation system with inner, outer, and colored shadows. | `box-shadow`, `inset`, `text-shadow`, blur radius, spread radius |
| **transformations** | 2D and 3D spatial manipulations of DOM elements. | `transform: translate() rotate() scale() skew()`, transform-origin |

   ```bash

   cd BridgeLabz-Training-3Y
   git checkout css-practice
   ```

2. Open any project in your browser or with VS Code **Live Server**:
