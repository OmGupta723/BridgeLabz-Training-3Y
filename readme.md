## 📌 Branch Directory & Module Details

### 1️⃣ [`html-practice`](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/html-practice) — HTML Foundations, Semantics & Forms
Encompasses foundational to advanced HTML5 markup, semantic document structures, multimedia integrations, and practical mini-projects:

- **`introduction-to-web/`**: In-depth theoretical exploration of web architecture, browser rendering engines (parsing HTML/CSS/JS), HTTP/HTTPS client-server communication, web servers (Apache, Nginx, Node.js), and development environment setup.
- **`Assignment_2_HTML_Basics/`**: 20 comprehensive exercises mastering core HTML tags (`<h1>`–`<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`, `<table>`), text formatting (`<strong>`, `<em>`, `<sub>`, `<sup>`), and internal anchor linking.
- **`Assignment_3_Semantic_HTML/`**: Real-world layouts utilizing semantic landmark elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`), including online resumes, conference schedules, restaurant menus, and university course directories.
- **`Assignment_4_Forms_Embedding/`**: Interactive forms with modern input types (`date`, `tel`, `file`, `email`), fieldsets, legends, client-side validation attributes, UTF-8 character encoding standards, and multimedia `<iframe>` embedding (YouTube videos, Google Maps).
- **`practice/html/`**: Practical hands-on tasks:
  - **Task 01:** Professional Developer Resume
  - **Task 02:** College Academic Timetable Layout (`colspan`/`rowspan`)
  - **Task 03:** Smart Portal Navigation Mockup
  - **Task 04:** Comprehensive Student Registration Form

👉 **[Explore the HTML Practice Branch](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/html-practice)**

### 2️⃣ [`css-practice`](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/css-practice) — CSS Styling, Layouts, Animations & Bootstrap
A comprehensive collection of modern CSS styling techniques, advanced layout systems, responsive web design, and UI components built with **Bootstrap 5**:

- **`ASSIGNMENT_10_SUBMISSION_OF_BOOTSTRAP/`**: 10 real-world web pages leveraging the Bootstrap 5 12-column grid, navbar, cards, alerts, modals, pagination, and utility classes:
  - Company Landing Page, Personal Portfolio, Product Catalog, Restaurant Menu, Themed Blog, Notifications Dashboard, Task Tracker with Badges, Pricing Plans, Pagination Controls, and Travel Agency Showcase.
- **`ASSIGNMENT_9_SUBMISSION_OF_CSS_RESPONSIVE/`**: 10 projects mastering mobile-first responsive web design, media queries (`@media`), fluid typography (`clamp()`, `calc()`), CSS filters (`grayscale`, `blur`, `brightness`), and responsive dashboards.
- **`ASSIGNMENT_8_SUBMISSION_OF_CSS_CLASSES/`**: 10 tasks focusing on advanced selectors (child, sibling, attribute), pseudo-classes (`:hover`, `:focus`, `:nth-child`), pure CSS tooltips via pseudo-elements (`::before`, `::after`), `@keyframes` animations, and box-sizing comparisons.
- **`ASSIGNMENT_7_SUBMISSION_OF_CSS_MODELS/`**: 6 modules covering CSS box models, border-radius, outline vs. border accessibility, linear/radial gradients, multi-layered shadows, and 2D/3D transformations (`translate`, `rotate`, `scale`, `skew`).
- **`ASSIGNMENT_6_SUBMISSION_OF_CSS_FLEXBOX_AND_GRID/`**: 6 production-ready layout projects utilizing CSS Flexbox (1D alignment) and CSS Grid (2D template areas), including Blog Layout, Admin Dashboard, Homepage, Portfolio, Pricing Section, and Product Gallery.
- **`Assignment_5_SUBMISSION_OF_CSS_BASICS/`**: 6 foundational projects exploring CSS Box Model, typography hierarchy, multi-column editorial newspaper floats, and webpage wireframes.
- **`practice-codebase/`**: Experiments on CSS Units (`px`, `em`, `rem`, `%`, `vh`, `vw`) and a reusable Student Profile Card component with skill badges.

👉 **[Explore the CSS Practice Branch](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/css-practice)**

### 3️⃣ [`javascript-practice`](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/javascript-practice) — Core JS, ES6+, OOP, DOM & Functions
Extensive coverage of JavaScript from language fundamentals and algorithms to modern ES6+ standards, Object-Oriented Programming, DOM events, and advanced function mechanics:

- **`Assignment_1_JavaScript/`**: 10 core algorithm scripts covering data types, control flow, loops, and conditions:
  - Academic performance evaluator, voting eligibility, data type inspector, tiered discount calculator, login greeting, math quiz generator, expense tracker, number guessing game, salary projection, and weather planner.
- **`Assignment_2_JavaScript/`**: 10 applied logic scripts solving practical business problems:
  - Shopping cart discount calculator, click counter, customer feedback analyzer, department KPI evaluator, home security checker, math utility suite (primes, factorials, Fibonacci), number classifier, product title slug generator, salary deductions, and student GPA analyzer.
- **`ASSIGNMENT_3_Submission of JS ES Feature/`**: 10 advanced scripts mastering modern ES6+ features and runtime mechanics:
  - Dynamic type parsing, employee bonus calculation (arrow functions & rest/spread), transaction validator, scope debugging & Temporal Dead Zone (`TDZ`), hoisting lab (`var` vs `let` vs `const`), pyramid pattern generator, smart calculator, `"use strict"` enforcement, JSON schema audit, and nested scope closures.
- **`ASSIGNMENT_4_Submission_of_JS_Classes/`**: 9 interactive OOP web applications with HTML and class-based JavaScript:
  - E-Commerce Product Manager, Student Form Validator, Library Management System, Custom Form Builder, Movie Ticket Booking, Employee Management System, Login Form Validator, Dynamic Object Updater, and Shopping Cart Totalizer.
- **`ASSIGNMENT_5_SUBMISSION_OF_DOM/`**: 9 dynamic browser applications utilizing vanilla DOM APIs and event listeners:
  - Product List CRUD, real-time Character Counter, Multi-Step Onboarding Form, Theme Switcher (Dark/Light mode), Image Gallery Viewer, Live Table Search Filter, Mouse Viewport Coordinate Tracker, Custom Accessible Dropdown, and Real-Time Form Validation.
- **`ASSIGNMENT_6_SUBMISSION_OF_JS_FUNCTION/`**: 9 in-depth tasks exploring JavaScript functional programming, memory models, and prototypes:
  - Callback functions, higher-order operations, regular `this` vs arrow lexical `this`, constructor prototype delegation, prototypal inheritance (`Object.create`), prototype chain traversal, private state encapsulation via closures, custom `Array.prototype.map` polyfill, and modern ES6 class inheritance (`extends`/`super`).
- **`practice-codebase/`**: Hands-on interactive web apps including an interactive Web Calculator, Real-Time Password Strength Checker, Dynamic Hex Color Code Generator, and Math/Array/Boolean utility labs.

👉 **[Explore the JavaScript Practice Branch](https://github.com/OmGupta723/BridgeLabz-Training-3Y/tree/javascript-practice)**

## 💻 Getting Started & Cloning

To clone and explore all branches of the repository locally:

```bash
# 1. Clone the repository
git clone https://github.com/OmGupta723/BridgeLabz-Training-3Y.git

# 2. Navigate into the repository directory
cd BridgeLabz-Training-3Y

# 3. Switch to HTML assignments and practice tasks
git checkout html-practice

# 4. Switch to CSS, Box Model, Flexbox, Grid & Bootstrap assignments
git checkout css-practice

# 5. Switch to JavaScript, ES6+, OOP, DOM & Advanced Functions assignments
git checkout javascript-practice

# 6. Return to the main branch
git checkout main
```
