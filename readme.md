## 💻 Practice Tasks & Components

### 🪪 Task 05: Student Profile Card (`practice-codebase/task_05_Student_Card/`)
A clean, modern student profile card component built with semantic HTML and custom CSS.

#### Features & Highlights:
- **Card Container Layout:** Centered card with structured padding, margin, and borders.
- **Badge Indicators:** Styled skill badges (HTML, CSS, Java, Problem Solving) with soft background highlights.
- **Interactive Button:** Styled call-to-action button (`Contact Me`) with hover effects.
- **Typography:** Balanced font hierarchy across headers and descriptive bio text.

---

## 🎯 Key CSS Concepts Covered

| Concept | Description |
| :--- | :--- |
| **CSS Box Model** | Controlling `margin`, `border`, `padding`, and `content` dimensions. |
| **Typography & Hierarchy** | Styling headings (`h1`-`h3`), body text, line-height, and font weights. |
| **Colors & Highlighting** | Applying color palettes, background highlights, and contrast for badges. |
| **Component Styling** | Designing reusable UI components such as cards, badges, and action buttons. |
| **Selectors & Specificity** | Leveraging class selectors, element tags, and inline style overrides effectively. |
