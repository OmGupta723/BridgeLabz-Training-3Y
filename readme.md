## 📚 Module Breakdown

### 1️⃣ Introduction to Web (`introduction-to-web/`)
- **Assignment 1:** Detailed theoretical and conceptual answers on:
  - How browsers process and render web pages (HTML, CSS, JS parsing).
  - Web development environment setup (VS Code, Live Server, Git, Node.js).
  - Web servers (Apache, Nginx, Node.js) and static vs. dynamic websites.
  - Roles of Frontend Developers, Backend Developers, and DBAs.
  - End-to-end client-server-API-database architecture flow.

### 2️⃣ HTML Basics (`Assignment_2_HTML_Basics/`)
- Basic tag structures: `<h1>`–`<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`, `<table>`.
- Text formatting: `<b>`, `<strong>`, `<i>`, `<em>`, `<sub>`, `<sup>`, `<mark>`.
- Internal page linking, bookmark anchors, and relative/absolute path handling.

### 3️⃣ Semantic HTML5 (`Assignment_3_Semantic_HTML/`)
- Structuring clean, accessible web pages using semantic landmark tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- Real-world layouts: Developer Resume, Restaurant Menu, University Department Hierarchy, Conference Timetable, and Student Performance Reports.

### 4️⃣ Forms & Media Embedding (`Assignment_4_Forms_Embedding/`)
- **Interactive Forms:** Input types (`text`, `email`, `password`, `tel`, `date`, `file`, `radio`, `checkbox`), fieldsets, legends, and validation attributes (`required`, `pattern`).
- **Embedding:** Integrating external multimedia with `<iframe>` (YouTube videos, interactive Google Maps).
- **Standards:** UTF-8 character encoding, symbols, and HTML entities (`&copy;`, `&lt;`, `&gt;`, `&amp;`).

### 5️⃣ Hands-on Practice Tasks (`practice/html/`)
- **Task 01 - Resume:** Well-formatted online resume with skills, education, and achievements.
- **Task 02 - Timetable:** Complex timetable utilizing `colspan`, `rowspan`, and table headers.
- **Task 03 - Smart Portal:** Portal navigation mockup.
- **Task 04 - Student Registration Form:** Complete onboarding form with validation and semantic fields.
