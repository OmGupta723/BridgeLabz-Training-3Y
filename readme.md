## 💻 How to Run & Preview

### Running Node.js Scripts (Assignments 1, 2, 3)

Make sure [Node.js](https://nodejs.org/) is installed:

```bash
# Checkout javascript-practice branch
git checkout javascript-practice

# Run Assignment 1 scripts
node Assignment_1_JavaScript/academicPerformance.js
node Assignment_1_JavaScript/mathQuizGenerator.js

# Run Assignment 2 scripts
node Assignment_2_JavaScript/cartDiscountCalculator.js
node Assignment_2_JavaScript/mathUtilityDashboard.js

# Run Assignment 3 (ES6+) scripts
node "ASSIGNMENT_3_Submission of JS ES Feature/Q1_Dynamic_Data_Parser.js"
node "ASSIGNMENT_3_Submission of JS ES Feature/Q7_Smart_Calculator.js"
```

Open any `.html` file directly in your browser or with VS Code **Live Server**:
